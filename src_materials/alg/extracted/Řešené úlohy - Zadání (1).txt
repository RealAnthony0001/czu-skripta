=== PŘEPIS STRUKTUROGRAMŮ Z OBRÁZKŮ ===
Př. 1: a = 1; b = 10; cyklus a < b { a = a + 2; b = b - 1; piš "*" }
Př. 2: a = 1; cyklus a <= 10 { b = 20 - 2a; selekce a > b: - piš "O" | + piš "X"; a = a + 1 }
Př. 3: a = načti; cyklus a > 0 { a = načti; piš a; a = načti }
Př. 4: a = 10; cyklus a > 1 { b = 10; cyklus b > a { selekce a mod 2 == 0: - piš "B" | + piš "A"; b = b - 1 }; a = a - 1 }
Př. 5: Hlavní program: x = načti; cyklus F(x) > 0 { selekce x > 5: - piš F(x)+1 | + piš F(x+1); x = načti }
       F(x): selekce x mod 2 == 0: - vrať 1 | + (selekce x == 2: - vrať x | + vrať 0)
